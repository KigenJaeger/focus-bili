# Bili+ 信息流净化器

本扩展现在同时整合了“小电视空降助手（BilibiliSponsorBlock）”的视频页能力：在 B 站视频中按社区标注自动跳过赞助、片头、片尾和互动提醒等片段。视频跳过功能使用 `bsbsb.top` 的公开服务；详细分类和跳过策略可在扩展设置页调整。弹窗中的“视频广告跳过设置”会打开该设置页。

Chrome 扩展（Manifest V3），用于净化哔哩哔哩网页信息流：

- 隐藏首页顶部**自动翻页的轮播大图横幅**（占空间大，且常混入推广/游戏广告）
- 移除信息流中的**广告卡片**（角标「广告」、外链、带 `creative_id`/`track_id` 推广参数的视频）
- 按**关键词**移除恰饭 / 暗广视频（标题、UP 主名、推广角标命中即移除）
- 移除卡片左上角标记为**直播、番剧、电影、电视剧、综艺、纪录片、国创、漫画、课堂、课程、赛事**的内容
- 按 **UP 主 UID 黑名单**移除指定创作者内容
- 弹窗内可开关各项、编辑关键词与黑名单、查看本次净化统计
- 诊断抓取改为手动会话：点击“开始抓取”后复现问题，再点击“结束并导出”；未开始会话时不记录页面变更

## 安装

1. 打开 Chrome，访问 `chrome://extensions/`
2. 右上角开启「开发者模式」
3. 点击「加载已解压的扩展程序」，选择本目录
   `D:\Personal\Desktop\Bili+\bili-feed-purifier`
4. 打开 `https://www.bilibili.com/` 即可看到效果

## 使用

- 点击工具栏扩展图标打开设置面板
- 所有更改自动保存，并立即在当前页面生效
- 已移除的内容不会自动恢复；需要完整还原时刷新页面即可

## 净化规则

| 类型 | 判定方式 |
| --- | --- |
| 轮播大图 | 仅隐藏 `.recommended-swipe`，保留 B 站页面控件 |
| 广告卡片 | 角标文字含「广告」、跳转非 bilibili.com 域名、链接含 `cid-click` / `cm.bilibili.com` / `creative_id`+`track_id` / `linked_creative_id` |
| 类型卡片 | 卡片徽标含「直播」「番剧」等默认类型关键词，或链接指向 `live.bilibili.com` / `/bangumi/` |
| 恰饭 / 暗广 | 标题、UP 主名或推广角标命中任一关键词（默认含：恰饭、暗广、软广、推广、种草、开箱、横评、评测、测评、实测、安利、避雷、商务合作、品牌方、金主、赞助、广告合作、打广告） |
| 黑名单 | UP 主空间链接中的 UID 与黑名单匹配 |

## 排查选择器失效

B 站首页的日常排查请优先使用弹窗里的“开始抓取”→复现问题→“结束并导出”。它只在会话期间记录精简的 DOM 变更摘要，报告保存在本地下载目录。

B 站改版后若出现漏杀或误杀（比如站点按钮被连带隐藏），用诊断脚本抓现场：

1. 在 B 站首页按 `F12`，切到 Console 面板
2. 打开 `tools/diagnose-page.js`，全选复制，粘贴到控制台回车
   （首次粘贴 Chrome 可能要求先输入 `allow pasting`）
3. 报告会打印在控制台、复制到剪贴板，并下载为 `bili-purifier-diagnose.json`

报告内容：

| 字段 | 用途 |
| --- | --- |
| `buttons` | 悬浮按钮往上 8 层祖先链及各层计算样式，定位是哪一层导致隐藏 |
| `rescuedByGuard` | 被 `:not(:has(...))` 保护救回的容器及其内部控件 |
| `cssMatches` | 注入规则实际命中的卡片，用于发现误杀 |
| `counts` | 各类卡片数量、JS 隐藏数、控件命中数 |
| `injectedCss` / `settings` | 注入样式全文与当前开关状态 |
| `meta.supportsHas` | 浏览器是否支持 `:has()` |

脚本只读，不修改页面、不发网络请求。

## 注意事项

- B 站前端改版可能导致选择器失效，届时需要同步更新 `content.js`
- 关键词默认偏激进，误杀时可自行删减；「推荐」等常见词默认未收录，需要可自行添加
- 统计为近似值，多标签页同时使用时可能略有偏差
